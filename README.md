# SoulSocial - Red social 
yamir britos, joaquin outomuro, jeremias silva, nacho gomez salamone

Desarollo de Sistema


## Descripción del proyecto
SoulSocial es una red social moderna pensada para estudiantes, jovenes y etc, con el objetivo de permitir una comunicación más directa, segura y organizada dentro de un entorno intuitivo. Permite a los usuarios publicar, comentar, reaccionar y enviar, manteniendo una interfaz completamente responsive y personalizable por idioma.

## ¿Cómo surge la idea / necesidad del proyecto?
En la actualidad, los estudiantes utilizan redes sociales o mensajería externa para organizar actividades, compartir novedades o comunicarse entre ellos. Esto genera problemas: exceso de distracciones, falta de seguridad y dificultad para centralizar la información.

Por eso se desarrolló SoulSocial, una plataforma propia, segura y diseñada específicamente para comunicación interna:

- Permite publicar novedades sin mezclar contenido externo.
- Facilita la comunicación rápida mediante chats privados.
- Mantiene un entorno controlado gracias al filtro automático de lenguaje inapropiado.
- Mejora la accesibilidad mediante traducción integrada (español/inglés), sincronizada con la base de datos del usuario.

## Tecnologías Utilizadas

### Frontend
- HTML5  
- CSS3 (diseño moderno + animaciones)  
- JavaScript  
- Sistema de idiomas dinámico (ES/EN)  
- Diseño responsive

### Backend
- Node.js  
- Express  
- Socket.io (tiempo real: likes, historias, chats)  
- Multer (subida de imágenes)  
- Middlewares personalizados  
- Filtro de contenido inapropiado

### Base de Datos
- MongoDB Atlas  
Colecciones:
- usuarios  
- posts  
- chats  
- likes

## Objetivos del proyecto
- Crear una red social funcional para estudiantes.  
- Mantener una interfaz estética, intuitiva y rápida.  
- Permitir comunicación segura y privada.  
- Implementar publicaciones, chats y perfiles de manera completa.
